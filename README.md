# 🕹️ Console JumpKing (C++ 콘솔 기반 점프킹 모작)

## 📌 프로젝트 소개
이 프로젝트는 유명 인디 게임 'Jump King'의 핵심 메커니즘을 Windows 콘솔 환경에서 C++로 구현한 게임입니다. 플레이어는 점프의 세기를 정교하게 조절하여 정상을 향해 나아가야 하며, 한 번의 실수가 큰 추락으로 이어지는 특유의 게임성을 재현했습니다.

직접 구현한 **콘솔 렌더링 엔진**과 **물리 시스템**을 통해 매끄러운 게임플레이와 다양한 지형 기믹을 제공합니다.

---

## 🎮 주요 기능 및 게임 특징

### 1. 정교한 점프 및 물리 시스템
- **점프 게이지**: `Space` 키를 누르는 시간에 따라 점프의 세기가 결정됩니다.
- **벽 충돌**: 점프 중 벽에 부딪히면 반동 없이 그대로 수직 하강하게 되어, 정확한 각도 계산이 필수적입니다.
- **포물선 이동**: 중력 가속도를 적용한 물리 연산으로 자연스러운 점프와 낙하를 구현했습니다.

### 2. 다양한 지형 및 트랩 (타일 기믹)
스테이지 파일(`.txt`) 내의 기호에 따라 서로 다른 물리 특성이 적용됩니다.
- `Ground (.)`: 기본적인 이동과 점프가 가능한 발판
- **`Ice (*)`**: 마찰력이 매우 낮은 얼음 지형으로, 착지 시 미끄러짐이 발생합니다.
- **`Spike (0~3)`**: 가시의 방향을 나타내며, 닿는 즉시 사망하여 해당 스테이지의 시작 지점에서 리스폰됩니다.
- `Grass (,)`: 일반 땅(`Ground`)과 동일한 물리적 성질을 가지며, 스테이지의 시각적 다양성을 위해 추가된 타일입니다.
- `Portal (u/d)`: 스테이지의 상단이나 하단 끝에 도달하면 다음/이전 구역으로 화면이 전환됩니다.

### 3. 스테이지 3: 타겟팅 탄환 (Bullet Spawner)
- 가장 난이도가 높은 스테이지 3에서는 플레이어를 위협하는 탄환 기믹이 등장합니다.
- **발사 시점 타겟팅**: 탄환은 **생성되는 순간의 플레이어 위치**를 향해 직선으로 날아갑니다. (실시간 추적이 아니므로, 탄환이 발사된 후 움직여서 피하는 전략적인 플레이가 필요합니다.)

### 4. 스테이지 에디터 (StageEditor)
- 마우스 클릭을 통해 직관적으로 스테이지를 설계할 수 있는 별도의 도구를 제공합니다. 
- 제작된 데이터는 `.txt` 파일로 저장되어 게임 내에 즉시 적용할 수 있습니다.

## ⌨️ 조작법
| 키 | 기능 |
| :--- | :--- |
| `←` / `→` | 좌우 이동 |
| `Space` (Hold) | 점프 힘 충전 |
| `Space` (Release) | 점프 실행 |
| `Esc` | 일시정지 및 메뉴 |

---

## 📂 프로젝트 구조
- **Engine**: 렌더러(Double Buffering), 입력 시스템, 물리 엔진 등 기반 시스템
- **Game**: 캐릭터 로직(Player), 타일 속성 관리, 스테이지 전환 로직 및 탄환 시스템
- **StageEditor**: 스테이지 제작을 위한 GUI 기반(콘솔 내 마우스 입력) 편집 도구
- **Assets**: 스테이지 구성 데이터 및 메뉴용 ASCII 아트 자료
